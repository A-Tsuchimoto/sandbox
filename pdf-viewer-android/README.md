# MarkPDF（仮）— 多色ハイライトができる軽量PDFビュワー（Android 試作）

スマホで読みながら、**指でなぞるだけで「始点からまっすぐな線」のマーカーを引ける** PDF ビュワーの最小構成の試作です。

## 方針

| 項目 | 方針 |
| --- | --- |
| 軽さ | **実行時の依存ライブラリなし**（AndroidX・Material も不使用）。PDF 描画は OS 標準の `PdfRenderer` |
| 課金 | フリーミアム。無料版＝機能制限あり → Pro 版＝数百円の**買い切り** |
| 広告 | **入れない**（無料版・Pro 版とも） |
| 特徴 | 多色ハイライト＋スマホ向けの「まっすぐ引ける」マーカー |

## 試作でできること

- PDF を開く（アプリ内の「開く」ボタン／ファイルアプリ等の「共有・開く」から）
- 縦スクロールでページ表示（幅フィット）。見えているページ±1ページだけ描画し、メモリを節約
- **マーカー**
  - 指を置いた点が始点、指の位置まで**直線**をプレビュー → 離すと確定
  - 角度が水平／垂直から ±10° 以内なら吸着（横書きの行・**縦書きの行**の両方に対応）
  - 乗算合成で描くので、下の文字は黒いまま読める
  - 太さ 3 段階（細・中・太）
  - マーカーモード中は **2本指でスクロール**
- **8 色パレット**（無料版は 2 色：イエロー・ピンク、残り 6 色は Pro）
- 消しゴム（タップ or なぞったハイライトを削除）、元に戻す（追加・削除とも）
- ハイライトはアプリ内に自動保存（PDF 本体は書き換えない）。ファイル名＋サイズで同一 PDF を判定するので、別の経路から開いても復元される

Pro 購入は未実装です。デバッグビルドでは「⋮ → Pro版について → 試作：Proを有効化」で全色を試せます。

## 構成

```
app/src/main/java/app/markpdf/
├── MainActivity.kt          画面・ツール切替・パレット・Pro ダイアログ
├── pdf/
│   ├── PdfDoc.kt            PdfRenderer のラッパー（専用スレッドで描画＋LRU キャッシュ）
│   ├── DocInfo.kt           表示名とハイライト保存キー
│   └── HighlightStore.kt    ハイライトのモデル・JSON 保存・Undo
├── ui/
│   ├── PageListView.kt      ページの縦並び表示と、見えている範囲だけの遅延描画
│   ├── PageView.kt          1 ページの表示＋マーカー／消しゴムのタッチ処理
│   ├── StrokeGeometry.kt    直線の吸着・当たり判定（単体テストあり）
│   ├── SwatchView.kt        色ボタン（選択リング・鍵マーク）
│   └── Palette.kt           色・太さの定義、無料で使える色数
└── billing/ProStatus.kt     無料／Pro 判定（今はフラグのみ）
```

ハイライトは「ページ幅・高さで正規化した始点と終点＋太さ」で保存しているため、画面サイズや回転が変わってもずれません。

## ビルド

Android Studio でこのディレクトリ（`pdf-viewer-android/`）を開くか、

```sh
./gradlew assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest  # 直線吸着・当たり判定のテスト
```

- minSdk 26（Android 8.0）/ targetSdk 36
- AGP 8.11.1 / Kotlin 2.2.0 / Gradle 8.14.3 / JDK 17 以上

> 補足：この試作を作成した環境からは Google Maven に接続できなかったため、APK のビルドまでは確認できていません。
> Kotlin コードは Android フレームワークの jar に対してコンパイルが通ること、単体テストが通ることを確認済みです。

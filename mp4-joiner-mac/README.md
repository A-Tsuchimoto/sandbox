# MP4 Joiner（Mac アプリ）

GoPro などで撮った旅行動画（MP4）を、**順番を決めて 1 本にまとめる**だけの Mac アプリ。
動画編集ソフトを立ち上げてタイムラインに並べて書き出す…という手間をなくすのが目的。

macOS 標準の動画機能（AVFoundation）だけで動くので、**ffmpeg や Python などの追加インストールは不要**です。

- 50 本程度までを想定（上限は設けていません）
- Finder からドラッグ＆ドロップ / 「＋ 追加」で動画やフォルダを追加
- ドラッグ・↑↓ボタン・「GoPro 順」「撮影日時順」「名前順」「逆順」で並べ替え
- **フェードなしなら再エンコードしない高速コピー**（画質劣化なし、数十 GB でも短時間）
- オプションで、つなぎ目を数秒かけて **フェードアウト → フェードイン**（映像・音声とも）
  - つなぎ目ごとにフェードする / しないを切り替え可能
  - GoPro が約 4GB ごとに自動分割した「同じ撮影の続き」のつなぎ目は、既定でフェードしない
  - 動画全体の最初と最後をフェードすることも可能
- 素材ごとに **180° 回転**（GoPro の上下逆さま映像を直す）。全素材を回転する場合は再エンコードなしの高速コピーのまま
- 再エンコード時は Mac のハードウェアエンコーダが使われるので速い（H.264 / HEVC、画質 3 段階）
- 解像度やフレームレートが違う動画が混ざっていても連結可能（解像度はいちばん多いものに揃え、縦横比が違うものは黒帯）

## インストール

1. [Releases の「MP4 Joiner Mac版（最新ビルド）」](../../releases/tag/mp4-joiner-mac-latest)から `MP4Joiner-mac.zip` をダウンロード
   （または Actions の最新ビルドの Artifacts から）
2. 展開してできた **MP4 Joiner.app** を「アプリケーション」フォルダへ移動
3. 初回だけ: ダブルクリックすると「開けません」と表示されるので「完了」で閉じ、
   **システム設定 → プライバシーとセキュリティ** の下の方にある「このまま開く」を押す
   （Apple の有料デベロッパ署名をしていないため。2 回目以降は普通に起動できます）

対応: macOS 13 Ventura 以降、Apple Silicon / Intel 両対応

## 使い方

1. 動画（またはフォルダ）をウィンドウへドラッグ＆ドロップ
   - GoPro の SD カードなら `DCIM/100GOPRO` フォルダごと入れると全部入ります
2. 「並べ替え → GoPro 順」→ 必要ならドラッグで微調整（`delete` キーでリストから外す）
3. フェードしたい場合は「つなぎ目をフェードアウト → フェードイン」をオンにして秒数を選ぶ
   - 各クリップの上に出る「前とのつなぎ目: フェード / そのまま」をクリックすると個別に切り替え
4. 上下が逆さまの素材は、行の右にある「180°」ボタンをオン（サムネイルも回転して表示）
   - 複数選択して右クリック →「180° 回転」でまとめて切り替えも可能
5. 「連結して保存…」で保存先を選ぶ → 完了したら「Finder で表示」

画面下に、高速コピーになるか再エンコードになるか、出力解像度、予想ファイルサイズが表示されます。

## 連結の仕組み

| 条件 | 方式 | 速さ / 画質 |
| --- | --- | --- |
| フェードなし & 全クリップの解像度・fps・コーデック等が同じ | そのまま繋ぐ（Passthrough） | 非常に速い / 劣化なし |
| 全素材を 180° 回転（他の条件は上と同じ） | そのまま繋いで向き情報だけ書き換え | 非常に速い / 劣化なし |
| フェードあり、一部の素材だけ回転、または形式が混在 | 1 本の映像として書き出し直す | 動画の長さに応じて時間がかかる / 「画質」設定に従う |

- 再エンコード時の解像度は、クリップの中でいちばん多いものに揃えます（同数なら先に並んでいる方）
- フレームレートは各クリップのものをそのまま使います（30fps と 60fps が混ざっていれば、その区間ごとに 30 / 60）
- 音声のないクリップの区間は無音になります
- 書きかけのファイルは保存先と同じフォルダの隠しファイル（`.mp4join-…`）に作り、完成したら置き換えます
- 処理中は Mac がスリープしないようにしています

### GoPro のファイル名と「GoPro 順」

GoPro は長い撮影を約 4GB ごとに分割し、`GX010123.MP4`, `GX020123.MP4` …（分割番号 2 桁 + ファイル番号 4 桁）
と名前を付けます。名前順に並べると分割番号が先に来て順番が崩れるので、「GoPro 順」は
**ファイル番号 → 分割番号** の順に並べます（旧形式の `GOPR0123.MP4` / `GP010123.MP4` にも対応）。

## 注意

- GoPro の GPS などのテレメトリ（GPMF）トラックは出力に含まれません（映像と音声のみ）
- 4K を再エンコードすると出力は元より小さくなります。画質を優先したい場合は「高画質」を選んでください

## 開発

Xcode（または Command Line Tools）の入った Mac で:

```sh
cd mp4-joiner-mac
swift test                    # 小さな動画を生成して実際に連結まで確認
swift run MP4Joiner           # アプリを起動
./scripts/build-app.sh        # build/MP4 Joiner.app と build/MP4Joiner-mac.zip を作成
```

GitHub Actions（`.github/workflows/mp4-joiner-mac.yml`）が push のたびにテストとビルドを行い、
main ではビルドした zip を Release `mp4-joiner-mac-latest` に置きます。

```
Sources/JoinerCore/    連結処理（動画情報の読み込み・並べ替え・連結プラン・書き出し）
Sources/MP4Joiner/     アプリの画面（SwiftUI）
Tests/JoinerCoreTests/ テスト
scripts/               .app の組み立て・アイコン生成
Resources/Info.plist
```
